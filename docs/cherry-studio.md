# Cherry Studio 配置核对

Cherry Studio 使用 OpenAI 兼容服务时，关键不是只填一个地址，而是确认供应商类型、Base URL 和模型 ID 三者一致。

## 配置字段

```text
供应商类型：OpenAI / OpenAI Compatible
API Key：使用本机安全存储，不提交到仓库
Base URL：https://api.91kun.top/v1
模型：从当前模型列表复制准确 ID
```

不同版本的 Cherry Studio 字段名称可能略有不同。若界面已经自动拼接 `/v1`，Base URL 不要重复填写；最终以客户端实际请求地址为准。

## 最小回归

保存配置后，新建一个短对话，只发送一句话。检查：

- 返回的 `model` 是否是刚选择的模型；
- 请求是否走到了预期 Base URL；
- 是否能看到 `usage` 或 Token 统计；
- `finish_reason` 是否正常结束；
- 控制台用量明细是否出现对应时间的请求。

## 常见现象

| 现象 | 检查方向 |
|---|---|
| `401` | API Key 是否属于当前 Base URL，是否有空格 |
| `404` | `/v1` 是否重复，模型 ID 是否来自当前列表 |
| `429` | 并发、频率和自动重试，不要循环猛发 |
| 能聊天但没有用量 | 客户端是否隐藏了 usage，去控制台对照 |
| 切换后仍是旧模型 | 关闭旧会话并重新打开，检查环境变量和配置覆盖 |
